1. Built-in Functions (Predefined in Python)
input(): Prompts and accepts user input from the console as a string.
print(): Displays output or text on the screen.
int(): Converts a value or user input string into an integer (whole number).
float(): Converts a value or user input string into a floating-point number (decimal number).
range(): Generates a sequence of numbers (e.g., range(1, 11) produces numbers from 1 to 10).
2. Module Functions
random.randint(a, b): A function from the random module that generates a random integer between specified lower and upper bounds (inclusive).
3. User-Defined Functions
calculate_bmi(weight, height): A custom function defined using the def keyword to calculate and return the Body Mass Index (BMI) using the formula $\frac{\text{weight}}{\text{height}^2}$.
